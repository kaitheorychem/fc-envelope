# 漸化式のまま実装し、数値的破綻は列和の向きで検出して縮退させる

- 日付: 2026-09-16
- 状態: 受理

g が大きく n も大きい領域では √m⟨m−1|U|n⟩ と g⟨m|U|n⟩ が桁落ちし、漸化式が破綻する（例: S=25 では n ≃ 20 付近から）。閉じた解析形（Laguerre 陪多項式）に置き換えれば破綻自体は避けられるが、**理論文書が「漸化式により求めた行列要素を二乗する」と定めている**ので実装は漸化式のままとし、破綻は検出して縮退させる方針を採る。解析形はテスト側の参照として使う。

2 つの打ち切りを**列和 Σ_m FC_mn の向き**で見分ける。FC_mn は非負なので、

- **m の打ち切り**（梯子が短い）は正の項を落とすだけなので列和は 1 を**下回る** → `m_max` を倍々に伸ばして解消する。
- **数値的破綻**は誤差が二乗されて正の側に積み上がるため列和が 1 を**上回る** → `m_max` を伸ばしても解消しないので、破綻が始まる直前の列までで n を打ち切り、`recurrence_limited` を立てる。

## 帰結

初期条件の g^m/√(m!) は m が大きい領域で桁溢れするため、対数で組み立てる。
