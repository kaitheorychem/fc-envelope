# 用語集を `CONTEXT.md` に一元化し、関係式・スキーマ・理由は重複させない

- 日付: 2026-09-16
- 状態: 受理

語彙の入口をルート直下の `CONTEXT.md` 1 つにする。この文書は**語の定義と、避けるべき
言い換えだけ**を持ち、以下は持たない。

| 内容 | 置き場 |
|---|---|
| 量どうしの関係式（S = g² など） | `docs/theory/vcc.md` |
| ファイルと API の形 | `docs/dev/spec/interface.md` |
| なぜそう決めたか | `docs/adr/` |

`CONTEXT.md` に関係式まで載せれば 1 箇所を見れば済むが、`vcc.md` の表を複製することに
なり、数式が更新されたときに 2 箇所を直す必要が生まれる。これは `docs/dev/agreement/` を
ADR へ移行したときに解消した「同じ問いに 2 つの答えがある」状態を作り直すことになる。

収録するのは衝突のある語だけに絞らない。`ZPL` / `サイドバンド` / `ホットバンド` /
`正準形` / `完全性` / `基準振動` は衝突していないが、この分野を知らない読み手（将来の
エージェントを含む）には通じない。用語集の価値は衝突の解決だけでなく、語彙の入口を 1 つに
することにある。
