# 作図スクリプトは参照構造のギャップから符号付きの遷移エネルギーの軸を描ける

- 日付: 2026-10-23
- 状態: 受理（ADR-0004 の E 軸はそのまま。表示の側に原点と向きを足す）

計算は ADR-0004 のとおり ZPL 相対の E 軸で行い、E_00 にあたる量を持ち込まない。ZPL の
絶対位置は図を描くときにだけ要るので、作図スクリプトの定数で与える（ADR-0057, 0062 と
同じく、絵の側の決定は作図スクリプトが持つ）。計算の途中で何かを足す必要がなく、計算量も
変わらない。

```python
REF_GAP = None          # 参照構造での 終状態 − 始状態 のエネルギー差。符号付き、X_UNIT で書く
REF_MINIMUM = "initial" # 参照構造がどちらのポテンシャルの底か。"initial" か "final"
```

`REF_GAP` を書くと、横軸は**符号付きの遷移エネルギー ε = (終状態) − (始状態)** になる。

```
ε00 = REF_GAP − λ    （参照構造が始状態の底）
ε00 = REF_GAP + λ    （参照構造が終状態の底）
ε   = ε00 − E
```

λ = Σ S_α ω_α は結果ファイルの `derived.reorganization_energy` から読む。`envelope` /
`lines` / 重ね描きの 3 本が持ち、結合の図（横軸が ω）は持たない。

## 理由

**与え方を手元の計算の手順に合わせる。** 参照構造で始状態と終状態を両方計算し、終状態の
勾配と調和近似から S と λ を得る、という手順では、直接手に入るのは参照構造でのギャップで
あって ZPL の位置ではない。ZPL の位置を手で求めて書かせると、λ を足すか引くかを利用者が
毎回考えることになる。λ は結果ファイルに入っているので、スクリプトが引き受ける。

**参照構造が始状態の底か終状態の底か、で書く。** 変位型調和振動子（同じ曲率）では、一方の
底で測った他方のポテンシャルの高さがどちらも λ になる。参照構造が始状態の底なら、そこでの
終状態は自分の底より λ 高い。終状態の底なら、始状態が λ 高い。この 2 通りで ε00 が決まる。

**向きは符号で決まり、吸収・発光の語を使わない。** ε を「終状態 − 始状態」と定めると、
振動量子を k 個作る線はどちらの場合も ε = ε00 + kω に立つ。E 軸ではサイドバンドが
E = −kω（ADR-0004）なので、ε = ε00 − E の 1 本の式で済む。終状態のほうが上なら ε00 > 0、
下なら ε00 < 0 になるだけで、向きを選ぶフラグは要らない。FC エンベロープそのものの定義に
吸収や発光は出てこない（ADR-0001）。光のスペクトルにするには双極子や周波数の因子を掛ける
別の層が要り、ここで扱うのはその手前の FC エンベロープの軸だけである。

**重心が参照構造でのギャップに来る。** ⟨E⟩ = −λ は温度によらないので、参照構造が始状態の
底なら、ε で描いたエンベロープの重心はちょうど `REF_GAP` に来る（垂直遷移のエネルギー）。
テストはこれを確かめる。

## 帰結

- 終状態のほうが下にあれば、図は負の ε の側に出る。正の値で見たければ `XLIM` を逆順に書いて
  軸を反転する。|ε| で描くつまみは足さない。符号付きの量として一貫させるためである。
- ε で描くと E とは向きが逆になる。重ね描きは横軸の範囲を小さいほうから取り、軸が反転しない
  ようにする。
- 縦軸の密度は |dε/dE| = 1 なので、単位の換算（ADR-0062）のほかに変わらない。
- 振動数の前因子は掛けない。横軸を写すだけである。
- ライブラリの `plot_*` と `show` は E 軸のまま描く（ADR-0062 と同じく、軸を選ぶ場所は
  作図スクリプトにだけある）。
