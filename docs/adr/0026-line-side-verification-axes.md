# 離散線側も解析解と恒等式で検証する

- 日付: 2026-09-16
- 状態: 受理（許容誤差の取り方は ADR-0042 が補う）

ADR-0015 の方針を離散線の系統にも引き継ぐ。次の 8 本を検証の軸に据える。

| 検証 | 何が確かめられるか |
|---|---|
| 漸化式 vs Laguerre 陪多項式 | 行列要素そのものの正しさ |
| 列和 Σ_m FC_mn = 1 | U のユニタリ性 |
| FC_mn = FC_nm | 漸化式とは独立な不変量 |
| n=0 列 = e^(−S) S^m / m! | ポアソン級数（ADR-0004 の検算式） |
| **線をガウシアンで畳む = エンベロープ** | 符号規約・熱占有・規格化の全部。独立な 2 実装の突き合わせ |
| Σ I → 1、⟨E⟩ → −λ | 0 次・1 次モーメント（ADR-0015） |
| 粗い閾値の結果 ⊂ 細かい閾値の結果 | 枝刈りの網羅性（ADR-0023） |
| 列和が 1 を上回る / 下回る | 破綻と梯子打ち切りの向きの違い（ADR-0024） |

5 行目が最も強い。エンベロープ（FFT）と離散線（漸化式）は共通コードをほとんど持たない独立な 2 実装なので、両者の一致は片方だけを見ていては気づけない誤りを捕まえる。
