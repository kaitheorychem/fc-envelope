# 離散 FC 因子をエンベロープと並置する第 2 の表現として追加する

- 日付: 2026-09-16
- 状態: 受理（`Conditions` を巡る構造は ADR-0035、命名は ADR-0031 が改める）

`compute_envelope` は時間相関関数のフーリエ変換によりスペクトル全体を高精度に与えるが、「どの振動モードが何量子ぶん効いているか」という個々の遷移の情報は積分に溶けて見えなくなる。定性的な考察では主要な離散 FC 因子だけを取り出すことに意義がある（`docs/theory/fc-factor.md`）。そこで FC 因子とその遷移エネルギーの組を列挙する系統を、エンベロープを置き換えるものではなく**同じ物理量の別表現として並置**する。

エンベロープと同じ「計算・保存・読み込み・描画」の自由関数 4 つを持ち（ADR-0011）、出力は `kind` で系統を区別する単一 JSON とする（ADR-0010）。符号規約は反転せずエンベロープと同一（ADR-0004）。

## 帰結

- `compute_fc_lines` は `Conditions` を受け取らない。離散線に `sigma` / E グリッドは要らず、必要なのは `temperature` だけだからである。`temperature` はキーワード必須とし、既定値を置かない（どの温度で計算したかが呼び出し側に必ず現れるように）。
- 出力の入力エコーも `conditions` ではなく `temperature` だけを持つ。**持たない値をエコーすると、再現できない情報を持っているように見える**ため。
- `transitions` からは n_α = m_α = 0 のモードを省く（200 モード系で 1 本の線に 200 個の 0 を持たせないため）。空タプルは ZPL を意味する。
- 線は**強度の降順**（同強度ならエネルギーの昇順）に並べる。「主要なもののみに絞る」という目的からは順位そのものが情報だからである。
- CLI の `lines` は `--show`（既定 10）で強度上位の線を標準出力に表示する。定性的な考察が目的なので、ファイルを開かずに主要な遷移が読めることを重視する。
