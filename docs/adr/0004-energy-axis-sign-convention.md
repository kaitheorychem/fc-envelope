# E 軸は理論式の符号のままとし、E = 0 を ZPL に置く

- 日付: 2026-07-25
- 状態: 受理

`docs/theory/time-ft.md` の式をそのまま実装し、符号の反転を行わない。E = 0 が ZPL（zero-phonon line）であり、E は ZPL からの符号付きエネルギー変位。振動量子を k 個生成するサイドバンドは **E = −k·ε_α（負側）**に立つ。v1 では E_00 オフセットを持たず、E 軸は常に ZPL 相対とする。

## 帰結

有限温度では (n+1) 項と n 項が非対称なため、**F(E) 自体が左右非対称**になる。この向きは吸収/発光の区別とは無関係に F(E) が持つ固有の性質である。向きの反転が必要になった場合は将来のラッパー層（ADR-0001）の責務とする。

検算用に、T=0・単一モードでは次のポアソン級数に帰着する（𝒩 は中心 −kε・標準偏差 σ の正規分布密度）。

F(E) = e^(−S) Σ_k (S^k / k!) 𝒩(E; −kε, σ)
