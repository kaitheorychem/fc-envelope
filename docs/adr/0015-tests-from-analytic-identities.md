# テストは解析解とモーメント恒等式を中核にする

- 日付: 2026-07-25
- 状態: 受理

参照データファイルの保守が不要で、数値コアを改良してもテストが生き残るため、解析解・恒等式による検証を中核に据える。M(τ) = ρ(τ)e^(−σ²τ²/2) のモーメント展開から次が**厳密に**成り立つ。

- 0 次: ∫F dE = 1 — 規格化因子の検証
- 1 次: ⟨E⟩ = −λ、λ = Σ_α S_α ε_α — **温度に依存しない**。符号規約（ADR-0004）とも整合
- 2 次: Var(E) = Σ_α S_α ε_α²(2n_α+1) + σ² — **ここにのみ温度が効く**

温度の扱いを誤ると 2 次モーメントだけが静かにずれるため、この 3 本が効く。
