# 出力は単一 JSON とし、入力エコーを正準形で埋め込む

- 日付: 2026-07-25
- 状態: 受理（`kind` と `spectrum` のキーは ADR-0031 / ADR-0032、`derived` と単位の書き出しは ADR-0047 が改める。入力エコーは ADR-0080 で入力の形を写さない `conditions` に置き換わった）

入力エコー・スペクトル配列・診断値・来歴を 1 ファイルに収め、`load_result` がこのファイルだけから結果クラスを完全に復元できるようにする。入力エコーは**常に正準形**（`coupling_convention` = `"huang_rhys"`、`coupling` は S の値）で書き出し、読み込み側に流儀の曖昧さを残さない。

## 検討した選択肢

N = 2¹⁴〜2¹⁷ 点で 0.3〜3 MB 程度のテキストになるが、エディタで中身が見え diff も取れる利点を優先してこれは割り切る。CSV / NPZ 等の追加出力形式は設けない。浮動小数点は Python 標準 `json` の repr ベース出力により round-trip で完全一致する。
