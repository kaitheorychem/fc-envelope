# 線形状を 1 つの値オブジェクトに集め、型階層にしない

- 日付: 2026-09-16
- 状態: 受理

現状、線形状がガウス型であるという知識が 3 箇所に散っている。`core.py` の減衰項
exp(−σ²τ²/2)、`plotting.py` の頂点値 1/(σ√(2π))、そして診断値 `sigma_tau_max`。将来
ローレンツ型・Voigt 型を足すとき 3 箇所すべてを探して直すことになるので、**線形状を
`Broadening` という値オブジェクトにまとめ、線形状に依存する計算をそこへ集める**。
エンベロープの計算と描画は、線形状がガウス型であることを知らなくてよい。

## 検討した選択肢

`Lineshape` プロトコルと `Gaussian` / `Lorentzian` / `Voigt` の型階層にする案は採らない。
3 つの型は時間領域ではいずれも ρ(τ) に掛かる実数の減衰因子にすぎず、Voigt はガウスと
ローレンツの積になる（exp(−σ²τ²/2 − γ|τ|)）。つまり種類が 3 つあるわけではない。
パラメータ (σ, γ) を持つ 1 つの族である。型階層にすると `Gaussian(σ)` と
`Voigt(σ, γ=0)` のように同じものが 2 通りに書け、等価判定・シリアライズ・入力検証が
面倒になる。

## 帰結

このリファクタリングで実装するのはガウス型だけで、γ を足すことは目的ではない。上の
構造にしておけば、γ を足す作業は `Broadening` の中だけで済む。Voigt 型を実装するときの
診断値と頂点値の扱いは、ADR-0038 と ADR-0039 に提案として残してある。
