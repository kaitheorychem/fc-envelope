# CLI の上書きは入力ファイルと同じ単位で読み、正準化の前に適用する

- 日付: 2026-09-17
- 状態: 受理（ADR-0012 の上書きの解釈を定める）

単位変換を入れると、入力ファイルで σ を eV で書いた場合に `--sigma 0.02` をどう読むかが
問題になる。CLI の値は入力ファイルと同じ単位・流儀で読み、入力ファイルの型に上書きして
から正準化する。

CLI の上書きは「入力ファイルの一部を書き換えて計算する」操作である（ADR-0012）。ファイル
と同じ単位で読めば、ファイルに書いてある値をそのまま CLI に移しても結果が変わらない。
検証と正準化の経路もファイルと同じ 1 本で済む。

## 帰結

今は `min_intensity=1e-4` などの既定値が `compute_fc_lines` と CLI に二重に書かれている。
CLI の既定値は「上書きしない」という意味の `None` にし、既定値は `Selection` の 1 箇所に
まとめる。
