# 計算の公開 API は自由関数のまま、中を 3 つの段階に分ける

- 日付: 2026-09-17
- 状態: 受理

`compute_envelope` と `compute_fc_lines` は、1 つの関数の中で検証・数値計算・診断値の算出・
警告の発報・結果の組み立てを順に行っていた。公開 API は自由関数のまま（ADR-0011）、中を
「数値計算」「診断値の判定」「結果の組み立て」に分ける。警告を発報して `messages` に記録
する処理は、両系統で共通の補助関数にする。メッセージ本文は各系統に手書きで残す
（ADR-0036）。

## 検討した選択肢

計算をオブジェクトにする案（`EnvelopeCalculator(broadening, grid).run(system, temperature)`）
は採らない。物理モデルは固定で、各表現のアルゴリズムも 1 つしかないので、オブジェクトに
して差し替える対象がない。

## 帰結

Voigt 型の線形状を足すときに触るのは、減衰因子と打ち切りの診断である。数値計算と診断値の
判定が分かれていれば、変更箇所が関数単位で分かれる。
