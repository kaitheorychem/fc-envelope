# モード表を外部 CSV から参照できるようにする

- 日付: 2026-09-15
- 状態: 受理（参照の置き場と、単位・流儀を担う欄の位置は ADR-0079 が置き換える。
  参照をパース時に解決する・相対パスは入力ファイル基準、は変わらない）

モードは「同じキーを持つレコードが並ぶ表」であり、外部の量子化学計算から機械的に生成されることが多い。表形式データの共通語は CSV で、awk / Excel / pandas などどこからでも作れる。そこで `modes` には従来の配列に加え、`{"path": "modes.csv"}` という参照オブジェクトを置けるようにする。

- 参照オブジェクトのキーは `path` のみ。未知キーはエラー（区切り文字指定などは将来の拡張余地として空けておく）。
- 相対パスは**入力 JSON ファイルのディレクトリ**を基準に解決する（カレントディレクトリではない）。
- `frequency_unit` / `coupling_convention` は JSON 側のトップレベルが引き続き担う。CSV は数値の表だけを持つ。
- 参照はパース時に解決し、パース後は配列で書いた場合と区別がない。
- `schema_version` は 1 のまま（従来の入力はすべて有効な上位互換の追加のため）。

## 帰結

ADR-0005 の「1 ファイルで全部再現できる」性質は、入力側では崩れる。再現性は**結果 JSON が担う**（ADR-0010）。結果の入力エコーは常に正準形のモード配列を埋め込むため、結果ファイル単体から計算を再現できる。

CLI には新しいオプションを追加しない。「`modes` は CLI で上書きしない」（ADR-0012）は維持する。
