# モードの集まりを `VibrationalSystem` という型にする

- 日付: 2026-09-17
- 状態: 受理

これまでモードの集まりは `tuple[VibrationalMode, ...]` のままで、2 つの計算がそれぞれ
振動数の配列・S の配列・λ を組み立てていた。これを不変のクラス `VibrationalSystem` に
し、振動数と S の配列、λ、温度を渡したときの占有数を持たせる。

決め手は、将来の入力の拡張（単位変換と流儀、入力フォーマットの見直し、非対角な基底からの
入力）がどれも最後は「正準化されたモードの集まり」に行き着くことである。この行き先を型と
して 1 つに決めておけば、入口がいくつ増えても計算側は変わらない。

## 帰結

- 中身は薄く保つ。系は分子に固有の情報だけを持ち、温度などの条件は持たない（ADR-0046）。
- 占有数の計算式そのもの（ボーズ分布、梯子 P(n)）は `physics.py` の配列・数値の関数に
  残し、`VibrationalSystem` はそれを呼ぶ。こうすると `physics.py` がモデルの型に依存しない
  （ADR-0041）。
