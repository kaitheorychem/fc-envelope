# 重ね描きの棒の高さを Voigt の頂点値へ一般化する

- 日付: 2026-09-16
- 状態: 受理（ADR-0027 の式を一般化する。縦軸を 1 本に保つ判断自体は維持）

ADR-0027 は棒の高さを h_ℓ = w_ℓ · G_σ(0) = w_ℓ/(σ√(2π)) と定めた。ADR-0034 で線形状が
(σ, γ) の 2 パラメータになるため、この頂点値を規格化 Voigt 関数の頂点へ一般化する。

    h_ℓ = w_ℓ · V(0; σ, γ),    V(0; σ, γ) = Re[w(i·a)] / (σ√(2π)),    a = γ / (σ√2)

ここで w は Faddeeva 関数（`scipy.special.wofz`）。等価な実形式は e^(a²)·erfc(a)/(σ√(2π))。

両極限で正しく帰着することを数値積分と突き合わせて確認済み（相対差 ~1e-11）。

- γ → 0: 1/(σ√(2π)) — ADR-0027 の現行式
- σ → 0: 1/(πγ) — 規格化ローレンツ関数の頂点

したがって ADR-0027 が担保した性質（孤立した線では棒の先端が曲線の山に一致する）は
線形状族の全域で保たれる。
