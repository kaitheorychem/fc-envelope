# 作図スクリプトは単独で動き、結果ファイルを実行時に読む

- 日付: 2026-09-18
- 状態: 受理

生成された作図スクリプトは `json` と `matplotlib` だけで動き、`fcenvelope` を import
しない。データは実行時に結果 JSON から読む。

- **単独で動く**ので、パッケージの版にも仮想環境にも縛られない。中身を読めば何を描いて
  いるかが全部分かる。`plot_envelope` を呼ぶ形にすると、図の設定が関数の中に隠れて
  「スクリプトを読めば全部分かる」という目的そのものを失う。
- **データを実行時に読む**ので、条件を振って計算をやり直しても同じスクリプトが当たる。
  引数でほかの結果ファイルを指せるので、温度を振った比較にも使える。
- 描画の中身は `draw(ax, data)` に閉じる。notebook から import でき、既定の見た目を
  テストで留められる。

結果ファイルの形式が変わったときに `KeyError` ではなく読める文言で止まるよう、`kind` と
`schema_version` を確かめてから描く。生成されたスクリプトは利用者の手元に残り続けるので、
その版ずれは必ず起きる。

## 帰結

雛形が `plotting.py` の知識を抱えることになる。とくに重ね描きの棒の高さ（ADR-0027 の
w·L(0)）は、数式を展開して雛形に書き下す。利用者が手で書き起こす場合との差がいちばん
大きいのがこの部分である。

matplotlib 以外のツール向けの雛形は、多くのツールが JSON を読めず列指向のデータ書き出し
が要るので、ADR-0010 を開き直すことになる。必要になってから判断する。
