# τ 窓の打ち切りを、σ ではなく減衰因子そのもので診断する

- 日付: 2026-09-16
- 状態: 受理（ADR-0009 の診断値の 1 つを差し替える）

診断値 `sigma_tau_max = σ·τ_max` は、減衰が exp(−σ²τ²/2) だけだった前提の指標である。
ADR-0034 で γ が入ると σ = 0 の純ローレンツ型が正当な入力になり、そのとき
`sigma_tau_max` は常に 0 で**誤警報になる**（実際には exp(−γ|τ|) が減衰させている）。

そこで τ_max における減衰因子そのものを記録する。

    damping_at_tau_max = exp(−σ²τ_max²/2 − γ·τ_max)

現行の「σ·τ_max ≥ 6」は「減衰因子 ≤ e⁻¹⁸ ≈ 1.523e-8」と等価なので、閾値をそう置けば
**γ = 0 における現行の挙動が完全に保たれる**。

## 検討した選択肢

σ 由来と γ 由来の指標を 2 つ持つ（`sigma_tau_max` と `gamma_tau_max`）ことも検討したが
採らない。検出したい失敗モードは「τ 窓が閉じる前に減衰が完了していない」の 1 つであって、
σ と γ はその 1 つの現象への 2 つの経路にすぎない。指標を 2 つに割ると、**どちらも単独では
閾値を下回るが合わせれば十分減衰している**ケース（Voigt の典型）で誤警報が出る。
