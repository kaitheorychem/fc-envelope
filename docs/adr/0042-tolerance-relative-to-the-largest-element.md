# 精度検証の許容誤差を、最大値で正規化した相対誤差にする

- 日付: 2026-09-16
- 状態: 受理（ADR-0015 / ADR-0026 の検証方法を補う）

漸化式と Laguerre 解析形の突き合わせが `max|rec − ana| < 1e-11` という**絶対**許容誤差
だったため、S = 6 で 1.488e-11 となり失敗していた。判定を最大値で正規化した相対誤差に
改める。

    max|rec − ana| / max|ana|  <  1e-9

S = 6・m ≤ 25・n ≤ 12 では 1.488e-11 / 0.4008 = 3.7e-11 となり、余裕を持って通りつつ本物の
退行は捕まえられる。

この形を採る理由は 2 つある。**要素ごとの相対誤差は使えない**——スペクトルも FC 行列も
要素の大半がほぼ 0 で、0/0 になるため。そして**絶対許容誤差では S を広げるたびに同じ形で
破綻する**——比較しているのが「両方とも打ち消しを含む近似計算」である以上、判定は量の
大きさに対して相対的でなければ意味を持たない。

## 帰結

この失敗は ADR-0024 が記録した漸化式の破綻**ではない**。S = 6・n = 12 での列和のずれは
~1e-16 で機械精度に収まっており、破綻が起きるのは S = 25・n = 29 から（そこでのずれは
−0.26 と桁違いに大きい）。両者を混同しないよう、許容誤差の根拠（漸化式 12 ステップ分の
打ち消しで ~1e-10 の相対誤差が出る）をテストのコメントに残す。
