# エネルギーの正準単位を cm⁻¹ に固定し、単位変換は検証点だけ用意する

- 日付: 2026-07-25
- 状態: 受理

入力・内部・出力のすべてで cm⁻¹ 固定とし、それ以外は `UnsupportedUnitError` で即座に reject する。τ は cm（ε_α·τ が無次元）、温度は K、F(E) は 1/cm⁻¹（∫F dE = 1 が成り立つ密度）。

将来の拡張に備え、**単位を保持・検証する場所だけ確保する**。入力 JSON は `frequency_unit` を、出力 JSON は `energy_unit` / `intensity_unit` を持つ。将来変換を入れるときは、この「検証点」を「変換点」に差し替えるだけで済む。

## 検討した選択肢

数値は素の `float` / `ndarray` として保持し、単位ライブラリ（pint 等）は導入しない。変換ロジックを自前で実装することもしない。必要になった時点で変換ライブラリに委譲する。
