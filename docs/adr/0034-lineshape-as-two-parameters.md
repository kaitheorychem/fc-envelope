# 線形状を型階層でなく (σ, γ) の 2 パラメータ族として扱う

- 日付: 2026-09-16
- 状態: 受理（ADR-0017 の「ガウス以外の広がりを扱わない」を解除する）

ガウス・ローレンツ・Voigt はいずれも、時間領域では ρ(τ) に掛かる実数の減衰因子にすぎない。

- ガウス: exp(−σ²τ²/2)
- ローレンツ: exp(−γ|τ|)
- Voigt: exp(−σ²τ²/2 − γ|τ|) — 両者の積。畳み込みがそのまま積になる

したがって 3 つの「種類」があるのではなく、**2 つの独立なパラメータ (σ, γ) を持つ 1 つの
線形状族**がある。`Broadening(sigma, gamma)` という 1 つの値型で表し、`Gaussian` /
`Lorentzian` / `Voigt` という型階層は作らない。

## 検討した選択肢

型階層（`Lineshape` プロトコルと 3 実装）を検討したが採らない。多態は「種類が本当に違う」
場合に効くが、ここでは種類は見かけ上のもので、`Gaussian(σ)` と `Voigt(σ, γ=0)` は同じ物に
なる。**同じ状態への経路が 2 つある型**は、等価判定・シリアライズ・入力検証のすべてで
面倒を生む。JSON も `{"sigma": 150, "gamma": 0}` のほうが素直で、ADR-0033 の単位の扱いとも
噛み合う。

頂点値や τ スケールは多態ではなく (σ, γ) から計算する関数として持つ。

## 帰結

σ = 0 の純ローレンツ型が正当な入力になる（現行は `sigma > 0` を要求している）。これに
伴い τ 窓の打ち切り診断を改める必要がある — ADR-0038。重ね描きの棒の高さの式も一般化が
要る — ADR-0039。
