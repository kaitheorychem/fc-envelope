# 出力の名前は入力ファイルの名前から導き、`-o` は省略できるようにする

- 日付: 2026-09-20
- 状態: 受理（ADR-0060 の「生成先は `-o` の名前から作る」を `-o` がない場合まで広げる）

`run` と `lines` の `-o` を省略可能にする。省略時の出力は、**入力ファイルの拡張子を
除いた部分**に種類の接尾辞を付けた名前で、**入力ファイルの隣**に置く。

| 呼び出し | 結果 | 添う作図スクリプト |
|---|---|---|
| `fcenvelope run input.json` | `input_envelope.json` | `input_envelope_plot.py` |
| `fcenvelope lines input.json` | `input_lines.json` | `input_lines_plot.py` |

ほとんどの実行で出力の名前は入力の名前の言い換えでしかなく、毎回書かせる理由がない。

## 種類の接尾辞を外せない理由

拡張子を除いた部分をそのまま使うと、`input.json` の出力が `input.json` になり、**入力
ファイルを踏み潰す**。同じ入力に `run` と `lines` を当てたときも衝突する。接尾辞は飾り
ではなく、この 2 つを同時に塞ぐためにある。接尾辞があれば既定の出力名が入力名と一致する
ことはなく、入力を壊す道が規則として消える。

## 入力ファイルの隣に置く理由

カレントディレクトリではなく入力ファイルのディレクトリに置く。`modes: {"path": ...}` の
相対パスが入力ファイル基準である（ADR-0019）のと基準が揃い、どこから呼んでも結果の
置き場が変わらない。結果の隣に作図スクリプトと実効設定（ADR-0065）が並ぶので、1 つの
入力に関わるものが 1 か所にまとまる。

## 上書きの方針

既定名の出力は**黙って上書きする**。作図スクリプトを残す ADR-0060 とは逆になるが、理由は
そこに書いてある——残すのは「調整の成果がスクリプト側にしかない」からで、結果 JSON は
入力から一意に決まる成果物なので当てはまらない。再実行とは結果を作り直すことである。

名前を変えながら掃引する実行では今までどおり `-o` を書く。既定名は 1 つしかないので、
掃引で `-o` が要ることは変わらない。
