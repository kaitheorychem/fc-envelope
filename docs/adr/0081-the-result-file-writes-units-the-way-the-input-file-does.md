# 結果ファイルの単位は入力ファイルと同じ書き方で、値と表に添える

- 日付: 2026-09-24
- 状態: 受理（ADR-0047 の「単位はヘッダの `energy_unit` / `density_unit` に書く」を置き換える。
  単位を結果クラスではなく `io` が持つ、は変わらない）

結果ファイルはヘッダに `energy_unit = "cm^-1"` / `density_unit = "1/cm^-1"` を書き、値は素の数で
持っていた。これには 2 つの問題があった。

- ヘッダの欄は、ほかの単位も書けそうに見える。しかし読み込み側は `cm^-1` 以外を落とし、作図
  スクリプトはこの欄を読んでいなかった。
- 単位が書いてあるのは一部の量だけだった。σ・グリッド・λ・`d_tau` / `tau_max`・`mean_energy`
  の単位は、ファイルのどこにも書かれていなかった。

**結果ファイルの単位は、入力ファイルと同じ 2 つの書き方で書く。**

- 有次元の値 1 つは `[値, "単位"]` の組にする（入力の ADR-0072 と同じ）。
- 表（行の並び・列の配列）は、表のブロックに列ごとの単位を `<列名>_unit` で書く（入力の
  `[modes]` の `frequency_unit` と同じ、ADR-0079）。

```json
"conditions": {
  "modes": { "frequency_unit": "cm^-1", "rows": [{ "frequency": 1200.0, "huang_rhys": 0.25 }] },
  "temperature": 300.0,
  "broadening": { "sigma": [150.0, "cm^-1"] },
  "grid": { "e_min": [-4500.0, "cm^-1"], "e_max": [1000.0, "cm^-1"], "de": [4.0, "cm^-1"], "n_fft": 4096 }
},
"derived": { "reorganization_energy": [300.0, "cm^-1"] },
"diagnostics": { "d_tau": [3.83e-4, "cm"], "tau_max": [0.785, "cm"], "sigma_tau_max": 117.8, "...": "..." },
"spectrum": { "energy_unit": "cm^-1", "density_unit": "1/cm^-1", "energy": ["..."], "density": ["..."] },
"lines": { "energy_unit": "cm^-1", "rows": [{ "energy": -450.0, "fc_factor": 0.26, "weight": 0.23, "transitions": ["..."] }] }
```

## 決まりごと

- 組にするのは有次元の値だけである。無次元の値（S、FC 因子、重み、割合、比、点数、真偽）と
  温度は素の数で書く。温度を素の数（K）で書くのは入力ファイルと同じである。
- 単位の文字列は正式名で書く。書き出す単位は常に正準単位（エネルギー `cm^-1`、密度
  `1/cm^-1`、τ `cm`）である。
- 読み込みは正準単位だけを受け、ほかの単位は `UnsupportedUnitError` で止める。入力ファイルが
  知らない単位を拒むのと同じ、値の検証である。
- スペクトルは表だが、行ではなく列ごとの配列（`energy` / `density`）で持つ。点数が多い
  （2¹⁴〜2¹⁷）ので、1 行ずつ辞書にするとファイルが数倍に膨らむためである。列の単位の
  書き方は行で持つ表と同じである。
- 線の列（`lines`）は `energy_unit` と `rows` を持つ表にする。
- ヘッダの `energy_unit` / `density_unit` はなくす。

## 理由

プログラム全体で単位の書き方を 1 通りにそろえる。入力ファイルにはすでに「値に添える組」と
「表のブロックに書く列の単位」の 2 つがあり、結果ファイルはその 2 つを使うだけで、新しい
書き方を足さない。マニュアルで入力の書き方を覚えた人は、結果ファイルもそのまま読める。

ヘッダに単位を固定で宣言する案（単位の表を 1 つ置き、値は素の数）も検討した。値が素の数の
まま読めるのが利点である。採らなかったのは、入力と違う 3 つ目の書き方が増えるためである。
1 つの値を見ただけで単位が分かることも優先した。

## 帰結

- 結果ファイルの版は 4 のまま（ADR-0080 と同じ PR で入るので、版 4 はまだ出ていない）。
- 作図スクリプトの雛形は σ を `sigma[0]`、線を `lines["rows"]` で読む。
- `io` の読み込みは値ごと・表ごとに単位を確かめる。単位を持つ診断値は
  `io._DIAGNOSTIC_UNITS` の表に書く。診断値を足すときは、有次元ならここにも 1 行足す。
