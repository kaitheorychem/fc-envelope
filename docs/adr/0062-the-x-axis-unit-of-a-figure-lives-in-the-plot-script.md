# 描画の横軸の単位は作図スクリプトが持つ

- 日付: 2026-09-18
- 状態: 受理（ADR-0053 が未決として残した「指定場所」を決める）

ADR-0053 は単位の軸を 4 つ（`frequency_unit` / coupling / `broadening` / `grid`）に分け、
**描画の横軸の単位はそれらとは別の軸**だとしたうえで、指定場所を未決にしていた。候補は
CLI オプションと入力ファイルだった。

ADR-0057 の境界（入力ファイルは数を決める、作図スクリプトは絵を決める）から、答えは
どちらでもない。横軸の単位は**絵の側**なので、作図スクリプトの定数になる。

```python
X_UNIT = "cm$^{-1}$"
X_SCALE = 1.0        # eV にするなら "eV", 1.0 / 8065.543937
```

計算は常に cm⁻¹ で行われている（ADR-0002, 0054）ので、ここでするのは表示の掛け算だけ
である。縦軸の密度は 1/(横軸の単位) なので、割って ∫F dE = 1 を保つ。この対応は
生成物のコメントに書き下す。単位を変えたときに縦軸を直し忘れる、という間違いがいちばん
起きやすいからである。

## 帰結

`plotting.py` の軸ラベルは `cm^-1` 固定のままでよい。ライブラリ API は結果クラスを
そのまま描くものなので、単位を選ぶ場所を持たない。単位を変えたければ作図スクリプトを使う。
