# 振電相互作用の内部正準量を Huang-Rhys 因子 S にする

- 日付: 2026-07-25
- 状態: 受理（正準量 S の決定は有効。実装形は ADR-0033 が改める）

ρ(τ) の中で g は常に g² の形でしか現れず、g の符号は物理的に無意味である。したがって内部正準量を S = g² とし、√ の往復を発生させない。副次的に、再編成エネルギー λ = Σ_α S_α ε_α が自然に得られる。

入力で受け付ける流儀は `"g"`（S = g²）と `"huang_rhys"`（恒等）の 2 種のみ。変換は Enum + 変換関数のレジストリとして実装し、流儀の追加が 1 エントリで済む形にする。

## 帰結

無次元変位 Δ（S = Δ²/2）や再編成エネルギー λ_α（S = λ_α/ℏω_α）は、必要になった時点でレジストリに追加する。流儀の一覧と相互関係は `docs/theory/vcc.md` にある。
