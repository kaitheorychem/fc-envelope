# 端末に出す図は窓の半分に収め、tmux の中では passthrough に包んで送る

- 日付: 2026-09-30
- 状態: 受理（ADR-0061 の端末の解像度の決め方と、ADR-0084 の端末の判定を改める）

端末への出し方について、実際に使って 2 つの問題が分かった。

1. **大きすぎる。** 図の幅を窓の画素幅の 0.9 倍に合わせていた（ADR-0061）。横長の窓を
   最大化すると、縦横比 7:4.2 の図は高さが窓を超え、画面いっぱいになる。
2. **tmux の中では出ない。** tmux は既定で知らないエスケープ列を外の端末へ通さない。
   作図スクリプトの列は捨てられ、`show` の問い合わせも届かないので窓に回る（窓が開けなければ
   止まる）。

## 決まりごと

**大きさ**

- 図は窓の幅と高さの**両方**について、その `SHOW_SIZE` 倍（既定 0.5）に収まる大きさで描く。
  窓の画素数が分かれば、解像度を `SHOW_SIZE * min(窓の幅 / 図の幅, 窓の高さ / 図の高さ)` と
  逆算する。端末側で縮小させないという ADR-0061 の方針はそのままである。
- 窓の画素数が分からない端末では `SHOW_DPI` で描き、kitty の `r=` で窓の行数の
  `SHOW_SIZE` 倍の行に収めさせる。この場合だけは端末が拡大縮小する。
- 作図スクリプトの `SHOW_WIDTH` は `SHOW_SIZE` に置き換える。ライブラリの定数は
  `plotting.TERMINAL_SIZE` で、一致はテストで確かめる。

**tmux**

- 環境変数 `TMUX` があれば、画像の列を tmux の passthrough（`ESC P tmux; … ESC \`、中の
  ESC は重ねる）に包んで送る。tmux 3.3 以降で `set -g allow-passthrough on` にしてあれば
  外の端末へ届く。設定は利用者の tmux の側で行い、本プログラムは変えない。
- tmux は外の端末に描かれた画像を知らず、画像の後ろで自分のカーソルを動かさない。そのため
  画像にはカーソルを動かさない指定（`C=1`）を付け、画像の高さぶんの行を改行で送る。
  そうしないと次のプロンプトが画像の上に書かれる。
- `show` の判定（ADR-0084）は、tmux の中では包んだ問い合わせだけを送り、DA1 は送らない。
  tmux は外の端末の答えを中へ渡すが、DA1 には tmux 自身が即座に答えるので、「DA1 より先に
  画像の答え」という順序の判定が使えないからである。画像の答えが来ればその場で対応と決め、
  来なければ `KITTY_TIMEOUT`（0.5 秒）待って非対応とする。
- tmux の中で端末にも窓にも出せないとき、CLI の案内に `allow-passthrough` を加える。

## 理由

**0.5 の両向きの上限。** 一目見る図は、下に続く出力やプロンプトと一緒に画面に収まって
ほしい。幅だけで決めると窓の形しだいで高さが溢れるので、幅と高さの両方で抑える。

**tmux の設定を本プログラムから変えない。** `allow-passthrough` はペインの中のプログラムに
外の端末への任意の列を許す設定で、有効にするかどうかは利用者が決めることである。
本プログラムにできるのは、設定されていれば届く形で送ることまでである。

**tmux 3.4 で確かめた。** 疑似端末を外の端末に見立てて本物の tmux を起動し、
`allow-passthrough on` では問い合わせと画像が外に届き、答えが中へ返ること、`off` では
どちらも届かず `show` が案内付きで止まることを確かめた。外の端末が返した DA1 の答えは
tmux が飲み込み、中へは渡らなかった。

## 検討した選択肢

- **kitty の unicode placeholder を使う**: tmux が画像の位置を文字として管理できるので、
  ペインの切り替えやスクロールでも消えない。ただ画像の送り方と置き方が別の仕組みになり、
  作図スクリプトの 15 行に収まらない。一目見る用途には、消えることがあっても足りる。
- **tmux の中では `tmux show -gv allow-passthrough` と外の端末名で判定する**: 外の端末が
  実際に答えるかどうかは分からず、SSH を挟むとさらに当てにならない。問い合わせを包んで
  送れば、届けば答えが返り、届かなければ返らないので、それ自体が判定になる。
- **窓の大きさの割合を CLI のつまみにする**: 図のつまみを CLI に足さない（ADR-0057）。
  作図スクリプトでは `SHOW_SIZE` を直せばよい。
