# 品質の警告は、その値を実際に動かすつまみを名指しする

- 日付: 2026-09-20
- 状態: 受理（ADR-0070 が先送りした「警告文の助言をどう直すか」を決める）

ADR-0009 で、品質の警告は「何が起きたか」に加えて「どう直すか」を持つと決めた。
その助言のうち `edge_intensity_ratio` の "Widen e_min/e_max" は、ADR-0070 で
グリッドの指定が変わったあと、**当たらないことのほうが多い**助言になっていた。

端の折り返しを決めるのは出力窓ではなく**全域グリッド** `n_fft * de` である。`de` を
書いた指定では全域幅が 2 の冪への切り上げで決まるので、窓を広げても切り上げ先の冪が
変わらないあいだは 1 も動かない。文書に載せていた例で実測した値が次である。

| 窓 | `de` | 全域幅 | `edge_intensity_ratio` |
|---|---|---|---|
| −4000〜1000 | 5.0 | 10240 | 1.9e-4（警告） |
| −5000〜1000 | 5.0 | 10240 | 1.9e-4（変わらない） |
| −4500〜1000 | 4.0 | 16384 | 9.4e-8 |

助言どおりに窓を広げた人は、値が動かない理由を自分で突き止めることになる。警告が
直し方を持つ意味がここで失われていた。

**警告文は、その診断値を実際に動かす量を名指しし、いまの値を添える。** 窓と全域
グリッドのように取り違えやすい量があるときは、動かないほうも名指しして違いを示す。

```
edge_intensity_ratio = 0.00019 > 0.0001: spectral weight reaches the edge of the
full grid at |E| = 5120 and is aliased back. That edge is set by the full grid
n_fft * de = 10240, not by the window, which reaches |E| = 4000: widen it with a
wider e_min/e_max, or a smaller de, which rounds the point count up to the next
power of two. A larger n or shift only refines the grid.
```

同じ方針を他の 2 つにも通した。`window_captured_fraction` の助言は前から窓で正しい
ので、**こちらは窓そのものである**と書き添えて、端の折り返しと取り違えないようにする。
`sigma*tau_max` は ΔE で決まるので、`de` を小さくするほかに `n` や `shift` を上げても
同じだと添える。`shift` が効く側と効かない側がここで分かれる。

## 助言は入力の書き方に依らず正しいものだけを書く

`n` で書いた格子では全域幅が窓ちょうどなので窓を広げれば直り、`de` で書いた格子では
切り上げの余白ぶんは動かない。`EnergyGrid` は解決済みの `(n_fft, de)` しか持たない
ので、どちらで書かれたかは分からない（ADR-0070）。

そこで**どちらの書き方でも正しい文**だけを載せ、値のほうに判断させる。全域幅と窓の
両方を数値で出してあるので、2 つが同じなら窓を広げればそのまま効き、離れていれば
その差だけ窓を広げても効かないことが、警告を読んだ場所で分かる。

## 帰結

`_quality_messages` が `grid` を受け取る。閾値の持ち主である `broadening` を受け取って
いるのと同じで、助言が名指しする値の出どころを引数で受ける形である。判定と測定を
分ける ADR-0048 の形は変えていない。`Diagnostics` に項目は増やさない。全域幅は入力
エコーの `grid` から読めるので、診断値として二重に持つ理由がない。

## 検討した選択肢

- **文言は変えず usage.md にだけ書く**: 警告は端末とログと結果ファイルで読まれるもので、
  そこに文書は無い。直し方を警告が持つという ADR-0009 の形を保てない。
- **余白の有無で文言を切り替える**（`full_span > 2·e_half` なら「窓を広げても効かない」と
  書く）: 1 つの警告に 2 通りの文面ができる。数値を両方出せば同じことが読み取れるので、
  分岐を増やす理由がない。
- **`edge_intensity_ratio` を窓の端で測る**: 助言と指標は一致するが、窓の外で折り返した
  重みを見逃す。この指標は `total_area` では捕まらない失敗のためにあるので（ADR-0009）、
  測る場所を狭めては役に立たない。
