# E グリッドは明示指定のみとし、0 対称な全域グリッドで FFT してから切り出す

- 日付: 2026-07-25
- 状態: 受理（グリッドの指定の仕方は ADR-0070 が改める）

`e_min` / `e_max` / `de` は明示指定し、省略値も自動推定も設けない（条件を振ったときにグリッドが黙って変わるのを避けるため）。内部では 0 対称な全域グリッドで FFT し、最後に窓へ切り出す。この取り方により**出力の ΔE は指定した `de` ちょうど**になり、**E = 0（ZPL）が必ずグリッド点上に乗る**。

τ グリッドと E グリッドをともに FFT 標準順序で持てば、余分な位相因子なしに F(E_j) = ifft(M)_j / ΔE がそのまま成立する。並べ替えは表示用の最後の `fftshift` のみ。

## 帰結

出力の端点は `de` の整数倍にスナップされる（`e_min` / `e_max` ちょうどとは限らない）。またこの離散化から Σ_j F(E_j) ΔE = M(τ=0) = 1 が**厳密に**成り立ち、実装検証の軸になる（ADR-0015）。
