# 結果クラスには、計算で決まったものだけを持たせる

- 日付: 2026-09-17
- 状態: 受理（ADR-0010 の `derived` と単位の書き出しを io の責務にする）

これまで結果クラスは `reorganization_energy` と `energy_unit` / `intensity_unit` を持っていた。
どちらも計算結果ではないので外す。

- **λ** は系から一意に決まるので `VibrationalSystem` のプロパティにする。結果クラスに持た
  せると、系から計算した λ と保存されていた λ がずれうる。io は保存時に `derived` として
  書き出し、読み込み時は読み飛ばす。
- **単位** は、計算側が常に cm⁻¹ しか扱わない（ADR-0045）以上、結果クラスの中では常に同じ
  定数である。ファイル形式の知識として io に置く。単位変換を入れるときに触るのは io と
  入力ファイルの型だけになる。

## 帰結

λ の計算は決定的なので、`load → save` でファイルが変わらない性質（ADR-0008）は保たれる。
