# v1 のスコープを FC エンベロープに限り、吸収・発光を区別しない

- 日付: 2026-07-25
- 状態: 受理

FC エンベロープ F(E) 自体は吸収でも発光でもない中立な量なので、`spectrum_type` のようなフラグを計算に持ち込まない。吸収・発光へ進む際に必要になるのは薄い層（E ↔ ℏω_photon の写像と E_00、振動数プレファクタ、屈折率因子、遷移双極子による絶対強度規格化）だけなので、後付けのラッパー層として足せる。

## 帰結

ただし薄くない差分が一つある。厳密には吸収は始状態＝基底状態、発光は始状態＝励起状態であり、それぞれの状態の ω_α・n_α を使う。両者を同一のモードセットで済ませるのは鏡像（mirror-image）近似であり、これを破るには ρ(τ) の構造自体に手が入る。
