# 重ね描きは縦軸を 1 本に保ち、棒を F(E) の単位へ変換する

- 日付: 2026-09-16
- 状態: 受理（縦軸を 1 本に保つ判断は有効。頂点値の式は ADR-0039 が一般化する）

エンベロープ F(E)（1/cm⁻¹）と線強度 I（無次元）は次元が違う。素朴には縦軸を左右 2 本立てる（`twinx`）ことになるが、**これは採らない**。2 本の軸の高さの対応づけが恣意的になり、「この棒はエンベロープのピークと同じ高さだ」という、データにない対応を図が主張してしまうためである。

代わりに縦軸を 1 本に保ち、棒の側を F(E) の単位へ変換する。変換係数は恣意的な定数ではなく理論から決まる。ADR-0022 の通り F(E) は各線を幅 σ の規格化ガウシアンで畳んで足し上げたものなので、

h_ℓ = I_ℓ · G_σ(0) = I_ℓ / (σ√(2π))  [1/cm⁻¹]

は「その線が F(E) に立てる山の高さそのもの」であり、曲線と同じ縦軸に置いて**高さを直接読める**。

## 帰結

この置き方には検算としての意味もある。孤立した線では棒の先端が曲線の山に一致し（隣の線の裾が効かないため）、実装はこれを許容誤差 1e-9 で検証している。σ の中に何本も密集するところでは曲線が棒より高くなるが、これはスケールの都合ではなく「1 本では説明がつかない、重なりで出来た山だ」という事実の表示である。

σ は `envelope` 側の `conditions` から取る。`FCLinesResult` は σ を持たない（ADR-0021）ので、重ね描きは必ずエンベロープの条件に従う。
