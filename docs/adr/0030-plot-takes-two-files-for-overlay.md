# 重ね描きは新しいサブコマンドを足さず、plot に 2 ファイルを取らせる

- 日付: 2026-09-16
- 状態: 受理（2 ファイルを取るのは ADR-0061 以降 `script` サブコマンド。組み合わせの規則は
  そのまま移る）

`fcenvelope plot` はもともと `kind` を見て描き分けるので、種類の判定はすでにある。同じ仕組みで 2 ファイルの役割も決まるため、**与える順序は問わない**。エンベロープ 1 つと線リスト 1 つ以外の組み合わせ（同種 2 つ、3 つ以上）は使用法エラー（終了コード 2）とする。

`run` / `lines` の `--plot` は単独の図のままにする。重ね描きには両方の結果が要るので、結果を書き出したあとの合成として `plot` に置くほうが筋が通る。

## 帰結

エンベロープと棒に既定のサイクル色を共有させると同色になるので、重ね描きのときだけ明示的に色を割り当てる。単独の描画関数は既定色のままとし（`ax` を渡して複数条件を重ねたときにサイクルが効く）、挙動を変えない。
