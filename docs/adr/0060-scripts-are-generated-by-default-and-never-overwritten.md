# 作図スクリプトの生成は既定で行い、既存のものは上書きせずに残す

- 日付: 2026-09-18
- 状態: 受理（`-o` を省いたときの既定名は ADR-0063 が決める）

`run` と `lines` は結果 JSON に添えて作図スクリプトを**既定で**書き出す。計算したなら
図はほぼ必ず要るので、毎回オプションを付けさせる理由がない。

| 状況 | 振る舞い |
|---|---|
| 生成先がない | 書き出し、`wrote result_plot.py` と知らせる |
| 生成先がある | **書かずに残す**。`kept result_plot.py (--force-script to regenerate)` |
| `--force-script` あり | 上書きする |

調整の成果はスクリプトの側にしかないので、生成が既存のファイルを黙って潰してはならない。
「あるならエラーで止める」ではなく「残して知らせる」にするのは、条件を振って計算をやり
直す運用で毎回エラーになると使い物にならないからである。この規則なら
`fcenvelope run ... && python result_plot.py` が何度でもそのまま通る。

名前を変えながら掃引する実行のために `--no-script` を置く。`-o T100.json` … と 50 点
振れば既定のままではスクリプトが 50 本できてしまうが、そこで欲しいのは 50 本ではなく
50 個の結果を読む 1 本である。

## 検討した選択肢

ログを「頼まれたときと失敗したときだけ」書くと決めた ADR-0052 とは既定が逆になる。
ログは痕跡で、要るかどうかが実行のたびに変わる。作図スクリプトは**成果物**で、計算した
以上はほぼ必ず要る。逆にする理由はここにある。

## 帰結

生成先は `-o` の名前から作る（`result.json` → `result_plot.py`）。スクリプトはデータの
隣に残るものなので、データの名前を継ぐ。`--script FILE` で明示もできる。
