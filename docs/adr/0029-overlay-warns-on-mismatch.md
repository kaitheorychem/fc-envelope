# 重ね描きの前提が崩れていたら警告し、描画は止めない

- 日付: 2026-09-16
- 状態: 受理

ADR-0027 の対応が成り立つのは、2 つの結果が同じモード・同じ温度で計算されている場合に限る。食い違っていれば描く前に `UserWarning` を出す（モードの不一致を優先して報告する）。ただし**描画自体は止めない**。意図的に別条件を並べたい場合もあるし、計算を完走させて品質は警告で知らせるという既存の方針（ADR-0009）に合わせる。

横軸は `envelope` の E 窓に合わせる。窓は利用者が明示的に選んだ範囲であり、図の枠として正しい。一方 `lines` は窓を持たず `min_intensity` 以上を全部返すので、窓の外に立つ線はありうる。**黙って落とさず、CLI が落とした本数を警告に出す。**
