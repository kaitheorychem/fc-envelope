# 作図スクリプトは画像ファイルと端末の 2 つに出し、plot サブコマンドを廃止する

- 日付: 2026-09-18
- 状態: 受理（ADR-0012 の `plot` サブコマンドと ADR-0030 の引数の規則を引き取る。
  画像の名前を引数で指したデータにも当てるのは ADR-0067）

図のつまみを CLI から全廃する（ADR-0057）以上、「とりあえず一目見る」経路も 3 段目の
側に持たせる必要がある。作図スクリプトに出力先を 2 つ持たせる。

- **端末**: 標準出力が端末のときだけ、kitty graphics protocol で図をそのまま出す。
  調整の輪（直す → 走らせる → 見る）はここで閉じる。
- **画像ファイル**: 毎回書く。書き出しは安く、常に最新でいてくれた方が扱いやすい。

判定は `sys.stdout.isatty()` だけで行い、端末の種類は調べない。パイプ・リダイレクト・
CI でエスケープ列を出さない、という一点だけが要るからである。対応していない端末や
sixel を使いたい場合は `show()` を書き替えればよい。

**解像度は出力先ごとに別に決める。** 画像ファイルは `DPI` で、端末へはそのときの窓の
画素幅（`TIOCGWINSZ`）から dpi を逆算して描き直す。端末側で縮小されないぶん文字が
ぼやけない。画素数を返さない端末では固定値に落ちる。kitty の `c=` で端末に縮小させる
手もあるが、縮小品質を端末の実装に預けることになるので採らない。

`fcenvelope plot` は廃止し、重ね描きの雛形を書き出す `fcenvelope script` を置く。引数の
形と組み合わせの規則（エンベロープ 1 つと線リスト 1 つ、順序は問わない）は ADR-0030 の
ものをそのまま引き継ぐ。`--title` / `--magnify` / `--dpi` / `--plot` は消え、対応する
つまみはスクリプトの定数になる。強い線を表に出す `lines --show` は図のつまみではないので
残すが、「見せる」が端末への図の出力を指すようになるため `--top` に改める。

## 画像の名前

画像は `fcenvelope-<stem>.png`（`result.json` → `fcenvelope-result.png`）。`spectrum.png`
では、スライドや共有フォルダに置かれた時点で何の図か分からなくなる。名前に負わせるのは
**どのプログラムの図か**までで、規則で情報を厳密に持たせようとはしない。図の中身を名前に
出したければ `-o` を選べばよい。

見た目に出ない覚え書きは PNG のテキストチャンク（`Software` / `Source` / `Description`）
に入れる。画像は単独で持ち出されがちなので、出どころが画像自身にも残る。

## 検討した選択肢

- **`plot` を「ちょっと見る」用に残す**: 描画の実装が 2 系統のまま残り、どちらで調整するか
  が二股になる。端末表示を 3 段目に持たせれば要らなくなる。
- **端末表示に外部パッケージを使う**: 「`json` + `matplotlib` だけで動く」（ADR-0058）を
  壊す。protocol を直に書けば 15 行で済む。
- **`kitten icat` を呼ぶ**: kitty 本体の付属コマンドが要る。同じ protocol に対応した
  ほかの端末で動かない。
