# 密度と重みを名前で区別し、`intensity` を使わない

- 日付: 2026-09-16
- 状態: 受理（ADR-0022 の用語を改める）

`intensity` が次元の違う 2 つの量を指していた。エンベロープ側は 1/cm⁻¹ の密度、線側は
無次元の重みである。同じ語で呼び続ける限り、両者の関係は毎回コメントで説明し直すことに
なるので、名前で区別する。

| 旧 | 新 | 意味 |
|---|---|---|
| `EnvelopeResult.intensity` | `density` | 1/cm⁻¹。∫F dE = 1 |
| `FCLine.intensity` | `weight` | 無次元。Σ_ℓ w_ℓ = 1 |
| `min_intensity` | `min_weight` | 保持する重みの下限 |
| `captured_intensity` | `captured_weight` | 拾えた重みの総和 |
| 日本語の「線強度」 | 「重み」 | |

この名付けの根拠は、2 つの量の関係が確率論の密度と質量そのものであること。
F(E) = Σ_ℓ w_ℓ L(E − E_ℓ) で、∫F dE = 1 かつ Σ_ℓ w_ℓ = 1。つまり {w_ℓ} は遷移上の離散
確率分布、F はそれを線形状で平滑化した密度である。

## 帰結

「なぜ重ね描きで棒に線形状の頂点値を掛けるのか」（ADR-0027）が、名前を見た
だけで分かるようになる。
