# 入力例は docs/readme/examples/ に置き、data/ には置かない

- 日付: 2026-09-17
- 状態: 受理（ADR-0053〜0055 の単位付き入力を、文書から指せる形にする）

単位を書いた入力ファイルの実例を 1 つ置く。置き場は `docs/readme/examples/` とし、
`data/` には置かない。

## 理由

`data/` は `.gitignore` で除外されている。利用者が自分の計算に使う入力とモード表の
置き場であり、追跡対象ではない。ここに例を置くとリポジトリに残らず、`README.md` や
`docs/readme/usage.md` から指しても読み手の手元には存在しない。

例は**利用者として使う人のための資料**なので、`docs/readme/` の下が置き場になる
（`README.md` の「ディレクトリ」節）。`docs/readme/usage.md` が入力ファイルの書き方を
説明しており、例はその説明が実際に動くことを示すものだからである。

`data/` の除外を例のためだけに緩めることはしない。否定の規則を足すと、追跡される
ファイルと除外されるファイルが同じディレクトリに混ざり、利用者が自分のデータを
置く場所という `data/` の役割が曖昧になる。

## 帰結

例が壊れていないことは `test/test_examples.py` が見る。文書に載っている入力が読める
ことは、単位フィールドを足した後の上位互換の確認そのものでもある。

例を増やす場合も同じディレクトリに置く。テストはディレクトリの中身を数え上げるので、
ファイルを足すだけでその例も検証される。
