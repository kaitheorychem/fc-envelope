# 線強度に始状態の熱占有を掛け、エンベロープと突き合わせ可能にする

- 日付: 2026-09-16
- 状態: 受理（`intensity` の呼称は ADR-0032 が改める）

FC 因子そのものに加え、始状態の熱占有 P(n_α) = (1−x_α)x_α^(n_α), x_α = e^(−ε_α/k_BT) を掛けた**線強度** I = Π_α P(n_α) FC_(m_α n_α) を併せて持つ。

I を導入する理由は、これが**エンベロープと直接突き合わせられる量**だからである。線を中心 E・標準偏差 σ のガウシアンで畳んで足し上げたものは `compute_envelope` の F(E) に一致する。これは ρ(τ) の母関数展開そのもので、T=0・単一モードでは ADR-0004 のポアソン級数に帰着する。FC 因子だけでは温度が入らないため、この対応が作れない。

## 帰結

全遷移にわたる I の総和は厳密に 1 になり、実装検証の軸になる。T = 0 では P(0) = 1 なので I = FC に一致する。

この畳み込みの関係が、重ね描きで縦軸を揃える根拠にもなる（ADR-0026）。
